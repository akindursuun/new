# New Web Builder

GrapesJS tabanlı, Next.js ile geliştirilecek görsel web sitesi oluşturma projesi.

## Planlanan yapı

- Next.js
- TypeScript
- GrapesJS Visual Editor
- Tailwind CSS
- Responsive sayfa oluşturucu
- Sürükle-bırak blok sistemi
- Hero, başlık, metin, görsel, video, buton, kolon, galeri, FAQ, accordion, CTA, form ve harita blokları
- Sayfa yönetimi
- Medya yönetimi
- SEO alanları
- Tema / renk / tipografi ayarları
- Plesk uyumlu production deployment

Plesk bağlantısından sonra uygulama altyapısı bu repository üzerinde geliştirilecektir.
